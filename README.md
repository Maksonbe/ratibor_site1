# Сайт ООО «Райтибор»

Многостраничный статический сайт: HTML5 + CSS3 + vanilla JavaScript,
без фреймворков, сборщиков и внешних библиотек.

## Структура проекта

```
raitibor-site/
├── index.html          главная: hero с витриной-«видоискателем», о компании, превью каталога, контакты
├── about.html          «О компании» и направления деятельности
├── products.html       каталог с фильтром по категориям
├── product.html        карточка товара (?id=…) + похожие товары
├── 404.html            страница «не найдено» (подключается сервером автоматически)
├── privacy.html        политика обработки персональных данных
├── consent.html        согласие на обработку персональных данных (отдельный документ — требование 152-ФЗ с 01.09.2025)
├── manifest.webmanifest  установка сайта на телефон / рабочий стол
├── css/fonts.css       локальные шрифты (@font-face)
├── css/style.css       все стили (тёмная и светлая темы, разделы пронумерованы в шапке файла)
├── js/
│   ├── products-data.js  данные: товары, категории, товары для превью и витрины
│   └── script.js         вся интерактивность (разделы пронумерованы в шапке файла)
└── assets/
    ├── favicon.*         иконки сайта
    ├── docs/*.pdf        технические описания товаров (кнопка на странице товара)
    ├── icon-*.png        иконки приложения (192, 512, maskable)
    ├── fonts/*.woff2     шрифты IBM Plex Sans/Mono и Space Grotesk (без запросов к Google)
    └── products/*.webp   фото товаров (WebP с прозрачным фоном)
```

## Как изменить данные

- **Товары** — массив `PRODUCTS` в `js/products-data.js`. Каталог, главная,
  витрина, страница товара и «похожие товары» обновятся автоматически.
  Необязательное поле `gallery` (список путей к фото, первое — главное)
  включает на странице товара галерею.
- **Товары в блоке «Продукция» на главной** — `FEATURED_PRODUCT_IDS`.
- **Устройства в витрине-«видоискателе»** — `HERO_SHOWCASE_IDS`.
- **Категории** — `PRODUCT_CATEGORIES` (`tag` — подпись рамки распознавания).
- **Телефон, почта, адрес, режим работы** в окне «Связаться» — объект `SITE`
  в начале `js/script.js` (на главной странице контакты также есть в HTML).

## Запуск

Открыть папку в VS Code → расширение **Live Server** → правый клик по
`index.html` → **Open with Live Server**.

## Что реализовано

- **Темы**: тёмная и светлая; выбор сохраняется, без выбора — следует за
  системной; применяется до отрисовки (без «вспышки»), синхронизируется между
  вкладками и при возврате кнопкой «Назад». Переключение — мягкий круг
  с растушёвкой от кнопки (View Transitions API), в Firefox — плавное
  перетекание цветов.
- **Платформы**: на iPhone, iPad и Mac — элементы в духе Liquid Glass
  (стеклянная шапка, кнопки, окна и уведомления с размытием и светлой
  кромкой); на Android — лёгкие сплошные поверхности и отклик на нажатие;
  на Windows/Linux — чёткие кромки и заметный фокус. Учтены вырезы экрана
  iPhone (safe area), поля ввода 16 px на телефонах (Safari не увеличивает
  страницу при вводе).
- **Любые экраны**: от кнопочных телефонов (240 px) и смартфонов в
  горизонтальной ориентации до 2K/4K-мониторов, ультрашироких экранов
  и проекторов. На больших экранах страница пропорционально масштабируется
  (CSS `zoom`, кроме Safari), на «низких» экранах витрина скрывается, отступы
  компактнее. Есть стили для печати и режима высокой контрастности.
- **Складные и двухэкранные устройства** (Galaxy Z Fold/Flip, Pixel Fold,
  Surface Duo): когда страница растянута на два экрана, колонки
  раскладываются по сторонам от шарнира (Viewport Segments API), окна
  открываются целиком на одном экране; в полусложенном режиме окно —
  на верхней половине.
- **iPhone Duo**: внешний экран 5,4″ — телефонная раскладка, внутренний
  7,6″ — раскладка под ширину (портрет, альбомная ориентация, Split View);
  при раскладывании/складывании переходы на мгновение отключаются, чтобы
  страница перестраивалась без «плавающих» элементов; открытые окна
  сохраняются.
- **Интерактивные доски и большие сенсорные экраны**: масштаб крупнее,
  чем на мониторе того же разрешения, увеличенные зоны нажатия.
- **Dynamic Island**: на iPhone уведомления («Ссылка скопирована» и т.п.)
  появляются сверху по центру чёрной «пилюлей» и плавно раскрываются вширь,
  как живые уведомления iOS.
- **Переходы между страницами**: шапка остаётся на месте, старая страница
  мягко уходит вверх, новая проявляется снизу (Chrome/Edge 126+, Safari 18.2+).
  При первом открытии и обновлении шапка плавно выезжает сверху.
- **Контакты**: «Контакты» в меню с любой страницы ведёт на блок «Свяжитесь
  с нами» на главной (без рывка, блок коротко подсвечивается); «Связаться»
  открывает окно с контактами (копирование в один клик) и формой.
- **Витрина на главной**: камера по очереди «распознаёт» устройства, подпись
  камеры меняется под устройство, смена — ровно в конце прохода сканирующей
  линии; объёмный наклон и блик под курсором, переключение стрелками; вне
  экрана — на паузе. Телефоны — скрыта, планшеты — под текстом, ПК — справа.
- **Каталог**: фильтр с количеством товаров и плавной перестройкой карточек,
  категория в адресе (`products.html?category=ip-cameras`), «Вы недавно
  смотрели» с анимированной очисткой, «Поделиться».
- **Страница товара**: галерея фото, кнопка «Назад» (туда, откуда пришли,
  иначе — в каталог), хлебные крошки, характеристики, похожие товары.
- **Формы**: единая проверка полей (`data-validate="name|phone|email|message|consent"`),
  «+7» и маска +7 (XXX) XXX-XX-XX в телефоне, обязательное согласие на
  обработку ПДн (отдельный документ), индикатор отправки, экран успеха.
- **Фон**: три едва заметных цветовых облака медленно дрейфуют по странице.
- **Анимации**: появление при прокрутке, счётчики, наклон карточек,
  «магнитные» кнопки, волна от клика. Всё отключается при системной
  настройке «уменьшить анимацию».
- **Доступность**: skip-link, ARIA, видимый фокус, focus-trap в окнах,
  возврат фокуса, управление с клавиатуры.
- **SEO**: title/description/Open Graph/canonical, JSON-LD schema.org/Product.
- **Производительность и приватность**: фото в WebP с прозрачным фоном,
  шрифты на самом сайте (ни одного запроса к сторонним серверам), скрипты
  с `defer blocking="render"` (страница показывается уже собранной), один
  обработчик событий на документ, обновления при прокрутке — не чаще раза
  за кадр.

## Технические описания (PDF)

Файлы `assets/docs/<товар>.pdf` сформированы из данных `js/products-data.js`
(поле `datasheet`) и скачиваются кнопкой «Описание, PDF» на странице товара.
При изменении характеристик PDF нужно пересоздать — генератор в репозиторий
не входит, его можно запросить у разработчика.

## Страница 404

GitHub Pages подключает `404.html` автоматически. На своём хостинге:
Apache — строка `ErrorDocument 404 /404.html` в `.htaccess`;
nginx — `error_page 404 /404.html;`.

## Проверка качества

Сайт проверен: html-validate (исходные и собранные скриптом страницы),
CSS-валидатор, ESLint, axe-core (доступность, обе темы, все страницы
и окна — 0 нарушений), контраст текста ≥ 4,5:1, все локальные ссылки,
24 разрешения экрана (от 240 px до 4K), складные устройства.

## Отправка форм

Сейчас отправка имитируется (статический сайт не может сам хранить заявки).
Вся отправка сосредоточена в одной функции `submitRequest()` в `js/script.js`.
Для подключения сервера (PHP + MySQL) достаточно заменить её тело на:

```js
return fetch('api/applications.php', { method: 'POST', body: data })
  .then(function (r) { if (!r.ok) throw new Error(r.status); });
```

Форма передаёт поля `name`, `phone`, `email`, `message`, `consent`,
`source` (`contact` или `request`) и `product_id` (для заявки на товар).
